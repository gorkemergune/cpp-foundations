Q1. BFS traversal

vector<int> Graph::bfs(int startId) const;

Return the IDs in the order breadth-first search visits them, starting from startId. BFS visits the start, then everyone 1 step away, then everyone 2 steps away. The result vector order is also the visited list.

Q1. DFS traversal

vector<int> Graph::dfs(int startId) const; void Graph::dfsVisit(int id, vector<int>& order) const;

Return the IDs in the order depth-first search visits them. DFS follows the first unvisited friend as deep as it can, and only comes back when a student has no unvisited friends left. The recursion keeps track of where to come back to.
