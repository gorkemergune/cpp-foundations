1. Problem statement

A photo app shows a ring of thumbnails. The thumbnails are stored in a std::vector<int> of image IDs, where 0 marks a deleted image. You implement three operations of the gallery:

  1. Part A — compact. Move every deleted image (0) to the end, keeping the order of the remaining images.
  2. Part B — preview. Return a new vector that shows the ring rotated left by k positions. The gallery itself must not change.
  3. Part C — commit. Rotate the gallery itself left by k positions, without a second vector.

Rotating left by one moves every element one position to the left and the first element to the end: {1, 2, 3, 4} → {2, 3, 4, 1}. Rotating by k repeats this k times. Rotating by n (the size) gives the original vector back, so k may be reduced modulo n.

Example scenario. The gallery is {1, 2, 3, 4, 5, 6} and the user swipes twice. rotatedCopy(g, 2) returns {3, 4, 5, 6, 1, 2} while g stays {1, 2, 3, 4, 5, 6}. After rotateLeft(g, 2), g itself is {3, 4, 5, 6, 1, 2}.
