1. Problem statement

A weather station stores the readings of one day in a plain C array int a[N]. The station's firmware is written in a style that is still common in course labs: no std::vector, the array and its length travel together as two parameters, and results that are not a single value come back through reference parameters.

Write minMaxIndex. It finds the index of the smallest and the index of the largest reading. If a value appears several times, report its first index. If the array is empty (n <= 0) there is no answer: return false and do not touch the output parameters.

Example scenario. Readings {3, 9, 2, 9, 2}: the smallest value 2 first appears at index 2, the largest value 9 first appears at index 1. The call minMaxIndex(a, 5, lo, hi) returns true and sets lo = 2, hi = 1.

const int a[] means “a pointer to the first element, through which I will not write”. int& minIdx is a reference to the caller's variable: assigning to it changes the caller's variable. This is how C++ returns several results without a struct.

Functions and operations you may use

OperationMeaning
a[i]element i, valid only for 0 <= i < n; nothing checks this for you
minIdx = …writes the caller's variable (reference parameter)
<algorithm> (min_element…)not allowed in A, B and M
Lab rules
  • Never read a[n] or beyond, and never read anything when n <= 0.
  • n <= 0: return false; the tests set the outputs to -100 before the call and check that they are still -100.

Input, output, constraints

Inputa points to n integers, -109 <= a[i] <= 109, n <= 105 (n may be 0 or negative).
Outputreturn value; minIdx, maxIdx only when the return value is true.
Complexityone pass, O(n) time, O(1) extra memory.

Soru ne istiyor?

Bir C dizisinde en küçük ve en büyük elemanın indeksini bulacaksın. Değeri değil, konumu döndürüyorsun. Fonksiyon iki sonucu int& parametreler üzerinden çağırana yazıyor, dönüş değeri olan bool da “cevap var mı?” sorusunu yanıtlıyor. Dizi boşsa çıktı parametrelerine hiç dokunmadan false dönmelisin.

C’den bildiğin, C++’ta değişen

  • Bozulma (decay). Fonksiyon parametresindeki int a[] yazımı aslında int* a demek. Uzunluk bilgisi kaybolur. Isınma programında sizeof(a) fonksiyon içinde 8 çıkıyor, çünkü bu bir pointer’ın boyutu. Derleyici bunu -Wall uyarısıyla da söylüyor.
  • Kopya yok. Vektörü değerle verince kopya oluşuyordu (Lab 01). C dizisinde kopya oluşmaz. fillSquares doğrudan çağıranın belleğine yazıyor. const bu yüzden önemli: const int a[] “okuyacağım, yazmayacağım” sözü veriyor.
  • Çıkış parametresi. C’de int* minIdx alıp *minIdx = i yazardın. C++’ta int& minIdx alıp minIdx = i yazıyorsun. Referans null olamaz, bu yüzden null kontrolü gerekmez.
Çözmeden önce kendine sor
  1. Döngüye başlamadan önce “şimdiye kadarki en küçük” için hangi indeksi seçmeliyim? Boş dizide bu seçim neden tehlikeli?
  2. Eşit değerde ilk indeksin kalması için < mı yazmalıyım, <= mı?
  3. Çıkış parametrelerine döngü içinde mi yazmalıyım, yoksa sonunda bir kez mi?

Neden bu yolu seçtik?

  • İzinli işlemler. Yalnızca indeksleme ve döngü kullandık. Uzunluk n parametresinden geliyor.
  • Sıra. Dizi değişmiyor (const). Sonuç “ilk görülen” kuralını izliyor.
  • Maliyet. Tek geçiş, O(n) zaman, O(1) ek bellek. İki ayrı döngüyle min ve max bulmak da O(n) olurdu. Tek döngü diziyi bir kez okuyor.
