2. Problem statement

An image-processing library keeps small square tiles in fixed 2-D arrays int m[MAXN][MAXN]; only the top-left n × n part is used. Implement two tile operations:

  • M1 · diagonalSum — the sum of the main diagonal (m[i][i]) and the anti-diagonal (m[i][n−1−i]). For odd n the centre cell lies on both and is counted once (LeetCode 1572).
  • M2 · transposeSquare — mirror the tile over its main diagonal in place: m[i][j] and m[j][i] exchange values. Cells outside the n × n part must not change.

Example scenario. For {{1,2,3},{4,5,6},{7,8,9}}, the diagonals are 1+5+9 and 3+5+7; the 5 is shared, so the answer is 25. Transposing gives {{1,4,7},{2,5,8},{3,6,9}}.

In a 2-D parameter every size except the first must be written: the compiler needs MAXN to know where row i starts (&m[i][0] is i · MAXN ints after &m[0][0]).

Allowed and constraints

A, B, Vwalk with pointers: p != end, *p, p++. Never dereference end. Indexing is not the point of these exercises.
M1, M2m[i][j] with 0 <= i, j < n, 1 <= n <= MAXN. No second array in M2 (O(1) extra memory).
ComplexityM1 O(n), M2 O(n2) with each pair swapped exactly once.

Soru ne istiyor?

M1 ve M2 kare bir matrisin köşegenleriyle çalışıyor. Asıl zorluk iki noktada: tek n’de iki köşegenin kesiştiği hücreyi bir kez saymak ve yerinde transpozda her çifti yalnızca bir kez takas etmek. Bir çifti iki kez takas edersen matris eski hâline döner.

Çözmeden önce kendine sor
  1. i satırında ikinci köşegenin sütunu nedir? Hangi i için iki köşegen aynı hücreye düşer?
  2. Transpoz döngüsünde j nereden başlamalı ki (i, j) ile (j, i) çifti bir kez ele alınsın?
  3. A ve V’de begin parametresini doğrudan ilerletmek çağıranı etkiler mi?

Neden bu yolu seçtik?

  • İzinler. A/B/V pointer yürüyüşüyle, M1/M2 indeksle çözüldü. İkinci dizi kullanılmadı.
  • Korunan bilgi. n × n dışındaki hücrelere hiç dokunmuyoruz. Test bunu -99 değerleriyle kontrol ediyor.
  • Maliyet. M1 O(n), M2 n(n−1)/2 takas, yani O(n2) zaman ve O(1) bellek.
