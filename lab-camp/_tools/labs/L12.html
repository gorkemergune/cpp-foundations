1. Problem statement

A text tool needs three functions:

  1. Part A — reverseWords (LeetCode 151): return the words of s in reverse order, separated by exactly one space, with no spaces at the beginning or end. Words are separated by one or more spaces in the input.
  2. Part B — compress: run-length encoding. Every maximal run of the same character becomes that character followed by the run length in decimal: "aaabcc" → "a3b1c2", "aaaaaaaaaaaa" → "a12".
  3. Part C — minMaxTokens: like Lab 10's minToken, but return both the smallest and the largest integer of the line through two reference parameters. No integer: false, outputs unchanged.
