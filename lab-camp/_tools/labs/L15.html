1. Problem statement

Labwork 1, Assignment 1 (both terms) and Assignment 5 all start from the same class: IntSLList, a singly linked list of int with a head and a tail pointer. In the labs it is given ready; in the exam you are expected to know every line of it. Write the whole intSLList.cpp yourself.

The invariant that every function must keep: either the list is empty and head == tail == 0, or head is the first node and tail is the last node (tail->next == 0). Most course bugs (see the archive notes in materials/README.md) are a tail that was forgotten.

Course contracts to respect
  • deleteFromHead() / deleteFromTail() return the removed value. Their precondition is “not empty”: the course code does not check, so the caller must test isEmpty() first.
  • isEmpty() returns int in the course file (0 or 1). In conditions it behaves like a bool.
  • deleteNode(el) removes only the first node holding el; nothing happens if el is not in the list.
  • The destructor must delete every node and must not throw.

Soru ne istiyor?

Lab 14’teki serbest fonksiyonların sınıf hâlini yazıyorsun. Fark şu: artık bir tail pointer’ı da var ve her işlemden sonra doğru olmak zorunda. tail sona eklemeyi O(1) yapıyor, ama silmede sorumluluk getiriyor. Son düğüm silinince tail geri çekilmeli, liste boşalınca head ile birlikte 0 olmalı.

Çözmeden önce kendine sor
  1. Hangi fonksiyonlar boş listeyi ayrıca ele almak zorunda? Hangileri “tek düğüm” durumunu?
  2. deleteFromTail’de yeni tail’i nasıl bulurum? Bu neden O(n)? Doubly linked list bunu nasıl çözer? (Lab 17)
  3. deleteNode son düğümü silerse hangi üye değişkeni güncellemeliyim?

Alternatif

std::list<int> aynı işlemleri push_front, push_back, pop_front, pop_back ve remove ile hazır sunar. pop_back doubly linked olduğu için O(1), ama pop_* değer döndürmez (void).
