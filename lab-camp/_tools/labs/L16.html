Exam conditions

50-minute timer, only lab16.cpp, paper allowed and recommended. Draw each part before you type.

1. Problem statement

  1. Part A — reverseList (LeetCode 206): reverse the list by turning every arrow around. Do not create nodes and do not copy values: the test checks that the returned list consists of the very same node objects in reverse order.
  2. Part B — removeFirst: remove and delete the first node holding v; return whether one was removed. The head may change.
  3. Part C — middleNode (LeetCode 876): return a pointer to the middle node in one pass, without counting first. For an even length return the second of the two middle nodes (index n/2).

Çözmeden önce kendine sor
  1. A’da her adımda kaç pointer gerekiyor? Hangisini kaydetmezsen listenin kalanı kaybolur?
  2. C’de döngü koşulu fast->next != nullptr mı olmalı, fast != nullptr && fast->next != nullptr mı? Çift uzunlukta hangisi ikinci ortayı verir?

Neden bu yolu seçtik?

  • Üçü de O(n) zaman, O(1) ek bellek. A’da yeni düğüm yok. Test düğüm adreslerini karşılaştırıyor.

Alternatifler ve hangi kuralı bozdukları

  • A’yı değerleri bir vektöre kopyalayıp ters sırayla geri yazarak çözmek: sonuç aynı görünür, ama “düğümleri değil değerleri değiştirmek” ve O(n) ek bellek, “in place, relink” kuralını ihlal eder. 2021 Assignment 1’in arşiv çözümündeki swap_nodes tam olarak bu hatayı yapıyor.
  • A’nın recursive hâli (Node* rest = reverseList(head->next); head->next->next = head; head->next = nullptr;) doğru, ama O(n) çağrı yığını kullanır.
  • C’yi “önce say, sonra n/2 yürü” diye yapmak doğru ama iki geçiş, yani “one pass” kuralını ihlal eder.
