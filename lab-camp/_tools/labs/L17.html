1. Problem statement

Labworks 2, 3 and 5 and 2021 Assignment 3 are all built on the course's DoublyLinkedList<T>. Each node has next and prev. Removing from the tail becomes O(1), and a node can be unlinked without searching for its predecessor. The price: every operation must update twice as many arrows.

The whole class is a template, so everything lives in genDLList.h, which is your file this time. Implement the members marked L17-A … L17-M2. M1 removeValue(el) unlinks and deletes the first node holding el. M2 reverse() reverses the list in place by swapping each node's next and prev and then swapping head and tail.

Each definition outside the class repeats template <class T> and names the class as DoublyLinkedList<T>::. Inside the class body you may write just DLLNode<T>.

The node and the invariants

DLLNode<T>(el, n, p) creates a node with next = n, prev = p. After every operation: empty ⇔ head == tail == 0; otherwise head->prev == 0, tail->next == 0, and for every node p->next->prev == p. The tests walk the list forwards with next and backwards with prev; both must give the same sequence.
