1. Problem statement

In a circular singly linked list the last node does not point to nullptr but back to the first node. The slides keep such a list through one pointer, last: the last node is last, the first is last->next, so both ends are reachable in O(1). An empty list is last == nullptr; a single node points to itself.

M1 (midterm): delete the node that last points to and reconnect the circle; the node before it becomes the new last. M2: delete the first node. Both must handle the empty list (false) and the one-node circle (it disappears, last = nullptr).

Example. Circle 1 → 2 → 3 → 4 → (1) with last at 4. After deleteLast(last): 1 → 2 → 3 → (1) and last at 3.

Assumptions added for this lab

The midterm note only says “delete the node called last and link again”. Fixed here: the list is singly linked, last is passed by reference and must move to the predecessor, the deleted node is freed, and a circle of one node becomes empty. The tests check that the circle is closed after every operation.

Complexity

insertAtEnd, deleteFirst: O(1). deleteLast: O(n) — the predecessor of last is only reachable by walking around the circle.

Soru ne istiyor?

Vizedeki soru: tek yönlü dairesel listede last diye tutulan düğümü sil ve çemberi yeniden kapat. Tek yönlü olduğu için last’ın öncülünü bulmak üzere çemberin etrafında yürümen gerekiyor. Yürüyüşün sonu nullptr değil. “Başa döndüm mü?” ya da “bir sonraki last mı?” diye kontrol ediyorsun.

Çözmeden önce kendine sor
  1. Tek düğümlü çemberde last->next neyi gösterir? Bu durumu nasıl anlarım?
  2. last’ın öncülünü bulan döngünün koşulu ne olmalı?
  3. Silmeden sonra hem çemberin kapanması hem çağıranın last’ının yeni son düğümü göstermesi gerekiyor. Hangi sırayla?

Neden bu yolu seçtik?

  • Bir ok değişiyor, bir düğüm siliniyor, last güncelleniyor. Ek bellek O(1).

Alternatif

Doubly circular bir listede (prev ile) deleteLast da O(1) olurdu: last->prev öncülü doğrudan verir. Bu vizenin “tek yönlü” varsayımını değiştirdiği için soru sözleşmesini ihlal eder, ama veri yapısı tasarımı sorusunda doğru cevap olabilir. Bir başka hile: last’ın değerini önceki düğüme kopyalayıp onu silmek. Değer kopyalama “düğümü sil” sorusunda genellikle kabul edilmez. Sınav yönergesini oku.
