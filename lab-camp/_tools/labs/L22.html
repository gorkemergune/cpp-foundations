1. Problem statement

The slides build a stack on a linked list: the top is the head of the list, so push and pop are O(1) and there is no capacity limit (unlike SlidesStack.h). The course assignments use other names for the same operations — pushToStack and a popFromStack that returns the removed value — and the old midterm camp's LLStack<T> uses them too. Write that class yourself, as a template, in llstack.h.

M2 is a practice signature: pushFromStack does not exist in the course archive; it is defined here to train the “two stacks” midterm question (Lab 23). It moves the top node of source onto this stack — no new node, no copy of the value.

Contracts
  • popFromStack and peek on an empty stack throw std::runtime_error (as in the old camp). Compare: std::stack::pop is undefined there, the slides' pop() returns false.
  • size() is O(1): keep count correct in every member.
  • pushFromStack(source): false if source is empty or is this same stack; otherwise the node moves (the tests count nodes).
  • The destructor calls clear(); clear() must free every node and must not throw.

Alternatif ve ihlal ettiği kural

M2’yi pushToStack(source.popFromStack()) olarak tek satırda yazmak: davranış aynı görünür, ama bir düğüm silinip yenisi oluşturulur ve değer kopyalanır. Bu “düğüm taşınır, yeni düğüm yok” sözleşmesini ihlal eder. Canlı düğüm sayısı aynı kaldığı için alive sayacı bunu göremez, adres de güvenilir değildir (silinen düğümün belleği yeni düğüme verilebilir). Test bu yüzden şimdiye kadar oluşturulan düğüm sayısına (stackNode<T>::created) bakıyor. Sınavda “yalnızca push/pop kullan” deniyorsa doğru cevap tam olarak bu tek satırlık sürüm. Kural sorudan soruya değişiyor.
