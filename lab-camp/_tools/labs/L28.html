1. Problem statement

The full midterm question: a string is stored in a singly linked list, one character per node. Delete the middle node (and free it), then put the remaining characters, in order, into a new queue, and print the queue by dequeuing it.

Example. "ABCDE" → list A → B → C → D → E; the middle (index 5/2 = 2) is C; the queue receives A B D E; printing gives "ABDE". For "ABCD" the middle is index 2, the C → "ABD".

Assumptions added for this lab

“Middle” = index n/2 (Lab 18, LeetCode 2095). The queue is the slides' Queue; its items are int, so a char is stored as its code and converted back with (char)x when printing. “Print” means: build the returned string while dequeuing with dequeue(item&). M2 must free every node it created.
