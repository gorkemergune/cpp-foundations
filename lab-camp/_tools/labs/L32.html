1. Problem statement

A graph is stored either as an adjacency matrix (m[u][v] = 1 if there is an edge u → v) or as an adjacency list (for each vertex, the list of its neighbours). Build both from an edge list (A, B), then answer the Labwork 6 questions on a matrix (M1, M2): the in-degree of a vertex is the number of edges coming in (a column), the out-degree the number going out (a row), and the number of edges is the number of 1s — for an undirected, symmetric matrix each pair is stored twice.

Example (Labwork 6). The graph below has 7 two-way connections, i.e. 14 directed edges; vertex 4 has in-degree 1, vertex 3 out-degree 4.

Soru ne istiyor?

Graf haftasının ilk labı: iki temsil arasında dönüşüm ve Labwork 6’nın üç fonksiyonu. Matriste giriş derecesi sütundaki 1’lerin toplamı, çıkış derecesi satırdaki 1’lerin toplamı.
