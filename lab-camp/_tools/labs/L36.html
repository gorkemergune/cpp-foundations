1. Problem statement

A binary tree is either empty or a node with a value, a left subtree and a right subtree. Almost every tree function follows the same pattern: handle the empty tree, then combine the answers of the two subtrees. Write the counting functions (A, B), the three depth-first traversals (M1), the height as defined in 2021 Assignment 4 — the number of nodes on the longest root-to-leaf path, 0 for an empty tree (M2) — the level-order traversal with a queue (M3) and a function that frees the whole tree (M4).

Trees in the tests are written in LeetCode's level order: [1,2,3,4,5,null,6] lists the levels left to right, null marks a missing child.

Neden bu yolu seçtik?

  • Her fonksiyon her düğüme bir kez uğruyor: O(n). Özyinelemeli çözümler yükseklik kadar (O(h)) çağrı yığını kullanıyor. Dengeli ağaçta bu O(log n), tek kollu ağaçta O(n).

Alternatif

Özyinelemesiz inorder: bir std::stack ile sola gidebildiğin kadar git, sonra pop edip yaz ve sağa dön (genBST’deki iterativeInorder). Aynı O(n) süreyi verir, derin ağaçta çağrı yığını taşmaz.
