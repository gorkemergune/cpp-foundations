1. Problem statement

After building hash tables by hand (L40, L41), use the library's: std::unordered_map<K, V> (key → value) and std::unordered_set<K> (keys only) are chained hash tables with average O(1) operations and no order. std::map is a balanced search tree: O(log n) operations, but it iterates in sorted key order.

expressionwhat it does
m[k]the value of k; inserts k with value V() (0 for int) if it is missing — perfect for counting, wrong for “is it there?”
m.find(k)an iterator to the element, or m.end(); inserts nothing; it->first is the key, it->second the value
m.count(k)1 if present, 0 if not
s.insert(k).secondtrue if k was new

Soru ne istiyor?

Bu labın soruları üç kalıba indirgeniyor. Sayma (A, B, M2): count[x]++. Görüldü mü, nerede? (M1, X): değeri son görüldüğü indekse eşleyen bir map.
