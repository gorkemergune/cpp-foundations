1. What you build

A command-line tool that reads student results, one per line, from the keyboard or a file, throws away malformed lines and prints a short report. The textbook's “GradeBook” case study (slides above) does this with an array; you do it with a class that owns a std::vector<Record>.

Suggested order

  1. count, then addLine with only the “two tokens” rule; run .\run.ps1 P01 — some rows fail, that is expected.
  2. Add the name and score rules one at a time; watch the failing rows disappear.
  3. readAll, average, best, failing, finally report.
  4. Build main_demo.cpp and run it on grades.txt.

Tasarım notları

  • Veri. Her satır bir Record { name, score }. Sınıf bu kayıtları std::vector içinde tutuyor. Dışarıdan doğrudan erişilemiyor (private), bu yüzden geçersiz bir kayıt hiçbir yoldan içeri giremiyor.
  • Doğrulama sırası. Önce token sayısı, sonra ad, sonra puanın biçimi, en son değeri. stoi("7x") 7 döndürür ve hata vermez. Bu yüzden önce “yalnız rakam” kontrolü gerekiyor. Uzunluk sınırı, stoi’nin çok uzun bir sayıda taşma hatası vermesini önlüyor.
  • Okuma ile hesaplamayı ayır. readAll akıştan okur. Hesaplamaları yapan fonksiyonlar akış görmez. Testler bu sayede istringstream ile çalışıyor, program std::cin ile.
  • const. Raporlayan fonksiyonlar nesneyi değiştirmiyor. const işaretleri sayesinde const Gradebook& üzerinden de çağrılabiliyorlar.
Kendine sor
  1. "Ece 7x" satırını reddetmek için hangi kontrol gerekiyor? istringstream >> int neden yetmez?
  2. Raporda ortalamayı iki basamakla nasıl yazarsın? (std::fixed, std::setprecision(2))
