1. What you build

A music player keeps a playlist and a “now playing” song. You can step forwards and backwards, remove songs and move a song one place up. A doubly linked list fits: stepping back is O(1) through prev, and moving a song only relinks nodes — no song data is copied.

2. Requirements and tests

PartWhat the tests check
Aempty playlist: size 0, current ""; after adding Intro 65 s, Song 185 s, Outro 59 s: size 3, total 309, current Intro; the prev links read Outro Song Intro.
Bprev() at the first song and next() at the last return false; removing the current last song makes the previous one current; removing the current first song makes the next one current; removing everything leaves no current song; adding afterwards works.
Cexact listing() text ("2. *Song (3:05)\n"); moveUp swaps by relinking (prev links checked), works up to the front, refuses the first song and unknown titles; cur still points at the same song.
Invariants
  • head, tail, every next/prev consistent; count equals the number of nodes.
  • cur is nullptr exactly when the playlist is empty; it never points at a deleted node.

Tasarım notları

  • Düğüm sınıfın içinde. struct Node private olduğu için kullanıcı yalnızca başlıkları görüyor. Liste yapısı dışarı sızmıyor. Lab 17’deki şablon sınıftan farkı bu: orada liste kullanıcıya açık bir araçtı, burada bir uygulamanın iç detayı.
  • Üçüncü pointer. cur, silmede en kolay unutulan pointer. Silinecek düğüm cur ise önce cur’u taşı, sonra bağlantıları kopar, en son delete yap.
  • moveUp’ta dört komşu. x ↔ a ↔ b ↔ y dizilimi x ↔ b ↔ a ↔ y olacak. Altı ok değişiyor, x veya y yoksa head/tail güncelleniyor. Değerleri (title, seconds) takas etmek daha kolay olurdu ama cur başka bir şarkıyı göstermeye başlardı. Test bunu yakalıyor.
